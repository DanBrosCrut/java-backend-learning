# java backend learning

Учебный репозиторий по программе стажировки: Java, Spring Boot, МойСклад, Agile/Scrum.

## Структура

- `docs/` — конспекты и заметки по теории
- `health-service/` — минимальный Spring Boot сервис с `GET /health`
- `REPORT.md` — недельный отчёт

## Требования

- JDK 21 (Temurin LTS)
- Maven 3.9+
- SDKMAN
